# Bean & Brew — Coffee Shop Cart Order

A responsive front-end demo for a coffee shop ordering cart, built with HTML, CSS and vanilla JavaScript.

## Features
- Coffee, cold drink and tea menu categories
- Add items to cart and adjust quantities
- Live subtotal, packaging fee and total
- Customer name and takeaway/dine-in selection
- Demo checkout confirmation
- Responsive layout for desktop and mobile

## Run
1. Extract the ZIP file.
2. Open `index.html` in any modern browser.
3. Add drinks to the cart and test checkout.

## Note
This is a front-end demo only. It does not store orders, connect to a server, or process payments.
